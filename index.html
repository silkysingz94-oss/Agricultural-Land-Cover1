METHODOLOGY
Administrative boundaries are loaded from the GitHub GeoJSON file. OpenStreetMap features are retrieved using the Overpass API and filtered to the selected administrative extent.

OSM agricultural mapping is volunteered geographic information. It is not a complete agricultural inventory or a direct measurement of cultivated land area.
